# AI Coding 工具使用说明

棱镜智教-PrismMind 在研发过程中使用 AI 辅助完成需求拆解、架构规划、代码生成、文档整理和调试建议。

## 使用边界

1. AI 仅作为研发辅助，不替代人工验收。
2. 关键功能包括 FastAPI 接口、SQLAlchemy/PostgreSQL 数据模型、Redis + Celery 异步任务、Chroma 检索和 Vue3 页面交互，均需人工运行验证。
3. 学术或教学内容生成需要保留知识库引用、安全检查和教师复核说明。
4. 如果演示环境接入真实大模型，应在私有环境变量中配置 API Key，不应提交到仓库。

## 当前模型配置

默认离线演示模式为：

```env
LLM_PROVIDER=mock
```

该模式可在无外部模型 Key 时保证本地验收稳定运行。真实模型接入应通过 `backend/.env` 或生产密钥管理系统配置，并在交付前完成单独验证。
