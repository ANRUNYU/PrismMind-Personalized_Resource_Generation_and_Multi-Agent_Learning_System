# 人工智能导论课程知识库：课程大纲

## 课程定位
人工智能导论面向计算机、电子信息、软件工程等专业本科生，帮助学生建立人工智能问题建模、搜索推理、机器学习和工程实践的基本框架。

## 学习目标
1. 理解人工智能的基本概念、发展脉络和典型应用场景。
2. 掌握状态空间搜索、启发式搜索、知识表示、机器学习基础等核心内容。
3. 能够使用 Python 完成小型智能系统原型，例如分类器、推荐器或路径搜索程序。
4. 能够识别模型评估中的训练集、验证集、测试集划分问题，避免数据泄漏。

## 章节结构
- 第 1 章：人工智能概述与应用边界
- 第 2 章：问题求解与搜索
- 第 3 章：知识表示与推理
- 第 4 章：机器学习基础
- 第 5 章：神经网络与深度学习入门
- 第 6 章：自然语言处理与多模态生成简介
- 第 7 章：AI 系统工程实践与伦理安全

## 评价方式
课程评价建议由过程性练习、项目实践、期末测试和学习反思组成。项目实践应强调问题定义、数据处理、模型训练、结果评估和复盘说明。
