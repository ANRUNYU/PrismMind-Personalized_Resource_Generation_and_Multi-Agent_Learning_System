# 人工智能导论课程知识库：机器学习基础

## 基本定义
机器学习是一类通过数据改善系统性能的方法。一个典型机器学习任务包括输入特征、输出标签、模型、损失函数、优化算法和评估指标。

## 训练与泛化
训练误差表示模型在训练数据上的错误程度，泛化能力表示模型在未见数据上的表现。仅追求训练误差很低可能导致过拟合。合理做法是划分训练集、验证集和测试集，并通过验证集调参，通过测试集进行最终评估。

## 常见任务
- 分类：预测离散类别，例如垃圾邮件识别、鸢尾花分类。
- 回归：预测连续数值，例如房价预测。
- 聚类：在无标签数据中发现结构，例如学生学习行为分群。
- 推荐：根据用户兴趣和历史行为推送资源。

## 易错点
1. 将测试集参与模型调参会造成数据泄漏。
2. 准确率不适合所有任务，类别不平衡时需要关注精确率、召回率、F1 等指标。
3. 模型复杂度越高不一定越好，需要在欠拟合和过拟合之间平衡。

## 实践建议
初学者可以先用 scikit-learn 完成完整流程：加载数据、划分数据集、训练模型、计算指标、记录错误样本，再尝试调整模型参数。
